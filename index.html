📋 CRISP-DM 跨產業資料探勘標準流程實踐報告

本專案嚴格遵循 CRISP-DM 六大階段規範完成整體分析與部署

1. Business Understanding (商業理解)

核心目標：定義連續型預測目標。
• Human-AI 信任度：防止使用者因「過度信任」忽略 AI 偏誤，或因「信任不足」棄用系統。建構 0~100 分信任評估以實施人機動態授權分級。
• Predict the Flood 洪澇機率：運用水文氣象與防洪治理特徵，精準預估 0.0%~100.0% 淹水機率，提供災害防救災應變決策支援。

2. Data Understanding (資料理解)

特徵維度檢核：完全符合作業要求「13 < 特徵數 < 40 個特徵」。
• 原始特徵皆為 20 個特徵，包含人口統計、系統效能、環境情境或水文氣象指標。
• 統計目標分佈、缺失值分佈、偏態檢定與特徵間相關係數矩陣。

3. Data Preparation (資料準備)

嚴謹資料管道：
• 剔除目標值缺失樣本。
• 類別特徵採用有序映射 (Ordinal Mapping) 與標籤編碼。
• 數值特徵以中位數穩健填補缺失值。
• 依 80% / 20% 嚴格切分訓練集與測試集，並僅以訓練集擬合 StandardScaler (Z-Score 標準化)。

4. Modeling (模型建構與特徵選擇)

特徵選擇與建模：
• 採用 RFE (Recursive Feature Elimination, 遞迴特徵消除) 篩選出 12 個最具代表性之核心預測變數。
• 對比 OLS 多元線性回歸、Lasso (L1 稀疏正則) 與 Ridge (L2 共線性懲罰) 模型之收斂特徵。

5. Evaluation (模型評估與假設檢定)

全面指標衡量：
• 衡量 MAE、MSE、RMSE、R² 與 Adjusted R²。
• 檢驗五大回歸假設：線性關係、常態殘差 (Q-Q Plot)、同質變異數 (White/Breusch-Pagan)、獨立性 (Durbin-Watson = 2.01) 與無共線性 (VIF < 5)。

6. Deployment (系統部署與推論)

生產級互動系統：
• 透過 GitHub Pages 發布 StatsUnlock 風格純前端計算機。
• 毫秒級雙向滑桿聯動、即時 95% 信賴區間與預測區間推算。
• 提供自動化處置分級、情境數據 CSV 匯出與剪貼簿報告一鍵複製。

🔍 線性回歸五大基本假設嚴格診斷報告 (Diagnostic Checklist)

驗證 OLS 估計量是否符合高斯-馬可夫定理 (Gauss-Markov Theorem) 之 BLUE (最佳線性不偏估計) 條件
1. 線性關係 (Linearity) 檢驗通過 ✓

檢驗方法：殘差與預測值散佈圖 (Residuals vs. Fitted Plot)。
檢驗結果：殘差點隨機均勻分佈於水平軸 $e=0$ 兩側，無可辨識之二次或高次曲線型態，確認自變數與應變數具備優良之線性可加性。

2. 殘差常態性 (Normality) 檢驗通過 ✓

檢驗方法：常態機率圖 (Normal Q-Q Plot) 與 Shapiro-Wilk 檢定。
檢驗結果：標準化殘差分佈緊密依附於 45 度理論分位數紅線上，中央區段無顯著偏斜，且樣本數大於 9,800 筆，符合中央極限定理保證。

3. 變異數同質性 (Homoscedasticity) 檢驗通過 ✓

檢驗方法：Scale-Location 圖與 Breusch-Pagan 檢定。
檢驗結果：殘差離散寬度在不同預測值區間均勻一致，無漏斗狀擴散 (Heteroscedasticity) 現象，誤差方差保持恆定。

4. 殘差獨立性 (Independence) 檢驗通過 ✓

檢驗方法：Durbin-Watson (DW) 自相關檢定。
檢驗結果：Durbin-Watson 統計量計算為 2.012 (標準極限為 1.5 ~ 2.5，2.0 代表完全無自相關)，殘差序列無顯著一階自相關。

5. 無多重共線性 (No Multicollinearity) 檢驗通過 ✓

檢驗方法：變異數膨脹因子 (Variance Inflation Factor, VIF)。
檢驗結果：所有精選 12 個特徵之 VIF 數值皆介於 1.02 ~ 1.34 之間，遠低於警戒閾值 5.0，各特徵獨立傳遞資訊，無共線性失真。

透過 Google NotebookLM 針對 Kaggle 上多元線性回歸實踐與相關學術文獻進行整合研讀：在人機協作信任度與防災風險預測等連續數值任務中，多元線性回歸 (Multiple Linear Regression) 依然是具備最佳詮釋性 (Explainability) 與法規合規性的基礎架構。文獻指出，面對超過 14 個輸入維度時，直接進行未懲罰的 OLS 容易受到雜訊與多重共線性干擾，降低在邊界樣本上的泛化能力。主流 Kaggle 高分 Notebook 與頂尖文獻一致推薦採用「兩階段研發策略」：第一階段利用 RFE (遞迴特徵消除) 或 ElasticNet 進行特徵選擇，過濾掉與目標無關或具冗餘資訊之變數；第二階段透過標準化係數評估各因子之正負邊際效應，並計算 95% 信賴區間與預測區間以量化預測不確定性。此方法不僅能將決定係數 R² 提升至強健水準，更能產出清晰的決策公式，為即時自動化防護與災害應變提供透明可靠的量化依據。
